# ChestLockLite v1.3.0 - Minecraft 26.3 Support

**Compatibility update for Minecraft 26.3**

## What's new
- Added support for **Minecraft 26.3**
- Built against Spigot API `26.3-R0.1-SNAPSHOT`
- `api-version` stays at `26.1.2`, so one jar runs on **26.1.2, 26.2, and 26.3**
- Updated the MockBukkit test dependency to `mockbukkit-v26.3` (4.119.0). All 39 tests pass.
- README and wiki now list 26.3 as supported

## Supported platforms
- Minecraft / Spigot / Paper / Purpur **26.1.2**
- Minecraft / Spigot / Paper / Purpur **26.2**
- Minecraft / Spigot / Paper / Purpur **26.3**
- Java 21+

## Upgrading
Drop-in replacement. No config or database changes. Your existing `config.yml` and lock data carry over as-is.

## Install
1. Download `ChestLockLite-1.3.0.jar`
2. Put it in your server's `plugins` folder (remove the old ChestLockLite jar)
3. Restart the server
